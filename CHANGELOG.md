## [0.2.19] - 2026-10-17

### Added
- **Intelligent Concierge Protocol for `garden: <prompt>` (Garden Guide v2.3)**:
  - Formally codified the intake concierge protocol in `src/guide.nim`, `skills/garden/SKILL.md`, and `skills/orchestrate-swarm/SKILL.md`.
  - When an operator prompts `garden: <prompt>`, the orchestrator evaluates the request's scope and presents an interactive `ask_question` triage modal with 3 structured options:
    - **Option 1 (Full Ceremony - RFE ➔ RFD ➔ RFC ➔ Swarm)**: For architectural shifts, new subsystems, major refactors, or cross-cutting migrations. Sows the idea as a persistent roadmap seed (`garden plant`), authors the Research/RFD, System Architecture/RFC, and Adversarial Audit documents, schedules monotonic locks and isolated Vine strands, and writes worker prompts to `/tmp/garden-<project>/`.
    - **Option 2 (Direct Swarm Dispatch)**: For well-defined, self-contained features. Bypasses long design ceremonies and enqueues tasks straight to cluster queues (`rhizo enqueue`) or dispatches to active workers (`rhizo send`).
    - **Option 3 (Inline Execution)**: For trivial 1-file fixes, documentation, or quick scratch tweaks executed directly in the main session.

## [0.2.18] - 2026-10-17

### Added
- **Three-Key Gate & Pre-Weave Adversarial Code Audit Pump (Garden Guide v2.2, `dialectical-pump`)**:
  - Expanded Two-Key Gate into the **Three-Key Gate**: Key 1 Mechanical Mergeability (`git merge-tree`), Key 2 Semantic Test Suite (`vine gate`), and Key 3 Adversarial Code Audit Pump.
  - Codified Stage 4 in `skills/dialectical-pump/SKILL.md` under the presumption of guilt across 5 pillars: Closed-Circuit Two-Point Diff, Holistic Integration, Literal Fidelity & Reference Parity, Aggressive Replacement Purge, and Structural Assertion Rigor.
  - Iterative **Delta Re-Pump Loop**: audits `git diff` deltas until 0 open defects remain before weaving.
- **Literal Fidelity & Reference Parity Mandate (Anti-Approximation)**:
  - Strict requirement rejecting "looks right" or "heuristic for happy paths" approximations. Enforces exact fidelity to operator specifications, characterization tests, and edge-case parity.
- **Structural Assertion Rigor (Anti-Green-Mirage)**:
  - Strictly prohibits loose assertions (`assert "foo" in bar`); mandates full structural equality (`assert actual == expected`) and negative controls.
- **Triad Update Subsystem & Shared Cadence Cache (`src/update.nim`, `garden update`)**:
  - Automatically queries registry updates for all three Axiomantic Triad packages (`garden`, `rhizo`, `vine`) on a 24-hour cadence.
  - Shares a single unified cache file (`~/.config/axiomantic/updates.json`) across the triad to prevent redundant network requests and duplicate update notices.
  - Configurable settings via CLI:
    - `garden update`: Check update status across the triad.
    - `garden update --apply`: Automatically run detected upgrade commands.
    - `garden update --skip <pkg@version>`: Suppress notifications for a specific release.
    - `garden update --disable`: Silence update check riders permanently.
    - `garden update --enable`: Re-enable daily update notifications.
    - `garden update --json`: Machine-readable telemetry of versions, install mechanisms, and available deltas.
- **Smart Installation Mechanism Auto-Detection**:
  - Dynamically inspects binary execution paths and symlinks (`expandSymlink`) to tailor upgrade commands to the exact environment:
    - `dev_source`: Dev repo checkout (`git pull && nimble build`) instead of destructive global npm overwrites.
    - `local_npm`: Project `./node_modules` (`npm/pnpm/yarn/bun update`).
    - `global_pnpm` / `global_yarn` / `global_bun` / `global_npm`.
    - `homebrew`: Homebrew Cellar (`brew upgrade`).
    - `standalone_binary`: Precompiled binary in `~/.local/bin`.
- **Autonomous Mode Suppression & AI Prompt Rider**:
  - Injects actionable `<!-- TRIAD_UPDATE_RIDER -->` block into `garden status` directing interactive AI assistants to prompt the operator with the auto-detected update command.
  - Automatically suppresses prompt riders when **Autonomous Mode** is active (`AUTONOMOUS_MODE=1` or `.autonomous` present in workspace) to guarantee zero interruptions during unattended execution.
